# BLAIR — soins capillaires experts

Démo e-commerce responsive en français pour la marque BLAIR. Le site reprend la direction visuelle fournie et utilise les images produit et lifestyle partagées avec le brief.

## Lancer le projet

```bash
npm install
npm run dev
```

Ouvrir ensuite [http://localhost:3000](http://localhost:3000).

## Fonctionnalités

- Navigation responsive et menus de gammes
- Recherche locale parmi les cinq produits
- Ajout au panier, retrait des articles et calcul du sous-total
- Comparateur avant/après manipulable à la souris et au toucher
- Navigation fluide vers les sections

Le panier sert uniquement à présenter l’expérience. Aucun paiement ni aucune commande ne sont traités. Les indicateurs de résultats sont des chiffres de démonstration, et les visuels avant/après sont illustratifs.
